# Dataformats exploration

I created this repository to prepare for a
[talk](https://www.data2day.de/veranstaltung-89225-0-vom-microservice-zum-ml-modell-eine-odyssee-durch-moderne-datenformate.html)
about what I referred to as data formats, even though the term is rather vague and
collects a bunch of different concepts.

One rather helpful output of this preparation is the [Explorer](explorer/), a
HTML/js based visualization tool to dive into the different formats that were covered in
the talk:

* Protobuf
* Apache Avro
* Apache Parquet
* Apache Iceberg
* Apache Arrow
* Lance

The numbers presented in the Explorer are based on the benchmark scripts in [bench](bench/).
Fair warning: Both were generated using Claude Code.
